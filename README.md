## 价格页上先看这三处，再看数字

荔枝商店的商品页会把授权拆成几栏标，同店的日历清单那页就是授权时长和免费更新时长各占一行。Moment 页面照这个思路找。

第一处是授权时长。三个月、一年还是三年，这一栏决定你能用多久。

第二处是免费更新时长。授权期和更新期是两回事，授权三年不等于三年内每个新版本都给你。两栏并排的时候，很多人只看了第一栏就下单。

第三处是授权设备数和使用范围。一台机器还是多台，能不能装在公司电脑上，页面会写。

三处看完再算单价，总价除以授权月数。算出来的数跟你实际会用的月数对一下：打算用满两年的人买三个月再续，多半比一次买两年贵；只想试两个月的人买三年，省下来的单价也用不上。

更新到期之后旧版本还能不能继续用，页面会说明，最终解释在开发商那边。这条别自己推。
